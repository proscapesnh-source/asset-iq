# Deploy PolyShield v2.7.0

1. In Supabase SQL Editor, run `supabase/migrations/20260828_v2_7_learning_reliability.sql`.
2. Replace the repository contents with this release, preserving the deployed environment variables.
3. Commit and push to the production branch used by Vercel.
4. On an iPhone, complete one corrected inspection and verify it appears in the Asset Passport.
5. Turn on Airplane Mode, complete a second inspection, reconnect, and verify the synchronization confirmation appears once.

The database migration must be installed before relying on automatic synchronization or correction-based learning.
