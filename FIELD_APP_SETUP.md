# PolyShield Field App

PolyShield v1.7 is a Progressive Web App. The same Vercel deployment can be installed on a technician phone and launched from the home screen.

- iPhone/iPad: open the production site in Safari, sign in, tap Share, then Add to Home Screen.
- Android/Chrome: use Install app when Chrome offers it or use the in-app Install button when available.
- Camera capture is enabled from inspection and asset-photo inputs.
- Inspection form fields autosave locally.
- v1.7 does not yet persist captured photo files offline; AI/photo upload/final sync require network connectivity. A queued offline photo-sync system is planned as the next field-hardening step.
