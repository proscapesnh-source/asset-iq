# v2.0 Field Deploy

Adds:
- Installable phone PWA workflow for deployed HTTPS builds.
- In-app Install control with iPhone/Android instructions.
- Vessel → Component hierarchy.
- Add/edit/remove valves, pumps, nozzles, manways, sensors, anodes, ladders, platforms and other child components.
- Component condition, calculated health score, status, manufacturer/model/serial/location and notes.
- Components remain linked to the parent vessel.
- Graceful compatibility if the component migration has not yet been run.
- Carries forward v1.9.2 iPhone UUID hotfix, talk-to-text, Take Photo / Photo Library, mobile Edit Asset, QR/tag tools and one-row navigation.
