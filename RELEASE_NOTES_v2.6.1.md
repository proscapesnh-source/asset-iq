# PolyShield Asset IQ v2.6.1 — iPhone Photo Hotfix

## Fixed
- Removed the unsupported silent iOS PWA photo download that could create an unreadable JPG and invalidate the in-app photo preview.
- Camera captures remain visible in the inspection and continue uploading to PolyShield normally.
- Tapping a photo still opens **Save to Phone**, which uses the native iPhone share sheet so the user can choose **Save Image**.
